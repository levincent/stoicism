# STORY-004 — Naviguer sur le site

## User Story
En tant que visiteur, je veux disposer d'une navigation claire entre les sections du site, afin de trouver facilement le contenu qui m'intéresse.

## Acceptance Criteria
- [ ] AC1 : un menu de navigation permet d'accéder aux sections Concepts, Philosophes, et (une fois connecté) Mes routines.
- [ ] AC2 : le site est responsive (mobile, tablette, desktop).
- [ ] AC3 : chaque page dispose des éléments SEO de base (title unique, meta description, structure de titres Hn cohérente).

## Hypothèses formulées
- Le menu affiche un état différent selon que l'utilisateur est connecté ou non (cf. STORY-005).
