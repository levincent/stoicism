# STORY-001 — Parcourir les pages de concepts stoïciens

## User Story
En tant que visiteur, je veux consulter une page dédiée à chaque concept stoïcien, afin de comprendre les notions clés de cette philosophie.

## Acceptance Criteria
- [ ] AC1 : chaque concept dispose d'une page dédiée avec définition, terminologie grecque/latine associée si pertinente (conforme à `docs/product/glossary.md`), et liens vers les philosophes qui l'ont développé.
- [ ] AC2 : une page d'index liste l'ensemble des concepts disponibles.
- [ ] AC3 : la page respecte les bases SEO définies (title, meta description, structure de titres cohérente).

## Hypothèses formulées
- Le contenu est rédigé en Markdown/MDX, une entrée = un fichier de contenu (collection Astro).
