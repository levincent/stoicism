# STORY-002 — Parcourir les pages de philosophes

## User Story
En tant que visiteur, je veux consulter une page dédiée à chaque philosophe, afin de découvrir sa vie, son école de pensée et ses citations.

## Acceptance Criteria
- [ ] AC1 : chaque philosophe dispose d'une page dédiée avec biographie courte, période et école de rattachement (conforme à `docs/product/glossary.md`).
- [ ] AC2 : la page liste les citations attribuées à ce philosophe (cf. STORY-003).
- [ ] AC3 : une page d'index liste l'ensemble des philosophes disponibles.

## Hypothèses formulées
- Le périmètre initial de philosophes couverts est celui listé dans `docs/product/glossary.md` (Marc Aurèle, Sénèque, Épictète, Zénon de Citium, Chrysippe, Cléanthe).
